## 영상 녹화 때 참고

- 수령 지점까지 가는 구간: 리허설은 `geo fix`로 바로 옮겼다(5초). 영상에서는 이 구간을 편집으로 줄이거나 자막으로 넘긴다
- 경유지 추가 직후 내비 화면은 "경유지 1개 포함 · 12분 5.1km" 경로 화면이 잠깐 나온 뒤 안내로 돌아가고, 다음 목적지가 "길목사거리 정차구역 5분 · 2.1km"로 바뀐다(`s1_4_waypoint_navi.png`, `s1_5_arrived.png`). 수령 완료 뒤에는 "서현역 12분 5.1km"로 돌아온다(`s1_8_route_back.png`)
- 운전·배달 화면은 아직 UI 담당 디자인 전이라 상태 글자만 나온다(캡처 그대로). 화면이 붙으면 `bash scripts/rehearsal.sh`를 다시 돌려 캡처만 바꾸면 된다
- 음성 겹침 검사는 앱 말 끝을 글자 수 추정(`SpeechTiming`)으로 본다. TTS `onDone`이 오지 않아 실제 소리 끝은 녹화로 확인해야 한다
