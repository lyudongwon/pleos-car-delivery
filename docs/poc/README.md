# PoC 근거표

기획서(지원서 1~6번)가 내세우는 주장마다 실제로 되는지, 근거가 무엇인지 적는다.
기능을 확인할 때마다 이 표의 상태와 근거를 고친다. 확인하지 못한 건 추측하지 않고 "미확인"으로 둔다.

상태: ✅ 확인됨 · ❌ 미확인 · ⚠️ 기획서와 다름(기획서 수정 필요)

## 기술 동작

## 성과 지표 (6-1)

| 기획서 주장 | 측정 방법 | 상태 | 근거 |
|---|---|---|---|
| 경로 위 수령 시 원래 경로에서 평균 0.5km 이내 이탈 | 같은 출발·도착에서 '가게 들러 포장'과 '경로 위 수령'의 추가 거리 비교 (F7·F8) | ✅ | 시흥동→기흥역(내비 17km·23분) 실측: 후보 5곳 모두 +0m, 가게 들러 포장 +1,000m. 이 거리에서 내비 거리는 1km 단위로 반올림돼 +0m는 0.5km 미만이라는 뜻이다 (11/12, `F7_pickup_measure_1112.json`). 11/11 서현역 경로(가게가 경로 바로 옆)는 `F7_pickup_measure_1111.json` |
| (참고) 가게 들러 포장 대비 추가 시간 | 같은 비교의 추가 시간. 기획안 성과 지표는 아니고 거리 비교의 보조 자료 | ✅ | 내비 실측 포장 +6분(+1km), 수령 +0분. 포장의 주차·하차·걷기 시간은 내비로 재지 않아 빠져 있다 (11/12, `F7_pickup_measure_1112.json`) |
| 주행 중 화면 터치 0회로 주문 완료 | S1 흐름을 끝까지 돌려 터치 카운터 확인 (F1·F5) | ✅ | 기어 D에서 대사 3개로 가게 제안 → 9,500원 확인 → 주문 완료, 화면 터치 0회 (11/11, `scripts/smoke_s1.sh`). 수령 지점·경유지는 F7·F8에서 이어 붙임 |
| 위치 입력 단계 3단계 → 0단계 | 배민에서 주차장 주소로 결제 직전까지 진행해 캡처, 본 앱과 비교 | ❌ | 수동 확인 |
| 하차 0회 | S1·S2 시연에서 확인 | ✅ | S1: 수령 지점에 세워 받고 "받았어"로 수령 완료(차 문 열림 이벤트 없음). S2: 기사가 차 옆까지 와서 전달하는 흐름. 실제 사람의 하차 여부는 시연 영상으로 보여줄 부분 (11/11) |

- 영상과 기획서에 쓰는 숫자는 여기 있는 원본에서만 가져온다.
